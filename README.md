# Projet Angular — Application web

Application frontend développée avec Angular et TypeScript dans le cadre d'un projet de développement web.

## Technologies
Angular 18, TypeScript, HTML, CSS et Node.js.

## Structure
- `src/` : composants et code de l'application.
- `public/` : ressources statiques.
- `angular.json` : configuration Angular.
- `package.json` : scripts et dépendances.

## Installation et exécution
```bash
npm install
npm start
```

Si le script `start` n'est pas disponible, utiliser `npx ng serve`, puis ouvrir `http://localhost:4200/`.

## Compilation
```bash
npm run build
```
